# Robot Decision Forest

[中文](README_CN.md) | [Русский](README_RU.md)

Это проект на языке C для выбора действий робота. Проект использует модель случайного леса, чтобы предсказывать следующее действие робота по данным датчиков.

На вход модель получает расстояние спереди, расстояние слева, расстояние справа и текущую скорость. На выходе модель возвращает класс действия робота.

## Возможности проекта

- Чтение обучающего и тестового набора данных в формате CSV
- Обучение нескольких деревьев CART с помощью Bootstrap-выборки
- Предсказание действия робота голосованием случайного леса
- Сохранение и загрузка модели
- Оценка модели на тестовом наборе: accuracy, confusion matrix, Precision, Recall и F1
- Расчет важности признаков

## Формат данных

Первая строка CSV-файла является заголовком. Последний столбец содержит метку действия.

```csv
dist_front,dist_left,dist_right,speed,action
63.9,2.5,27.5,22.3,2
73.6,67.7,89.2,8.7,0
```

Описание полей:

- `dist_front`: расстояние перед роботом
- `dist_left`: расстояние слева от робота
- `dist_right`: расстояние справа от робота
- `speed`: текущая скорость робота
- `action`: метка действия

Значения меток:

```text
0 = FORWARD
1 = LEFT
2 = RIGHT
3 = STOP
```

## Сборка проекта

Сборка через Makefile:

```bash
make
```

Также можно собрать проект напрямую через gcc:

```bash
gcc src/main.c src/robot_rf.c src/utils.c -o robot_rf -Wall -O2 -Iinclude -I. -lm
```

В Windows PowerShell, если создан файл `robot_rf.exe`, запуск выполняется так:

```powershell
.\robot_rf.exe
```

## Использование

### Обучение модели

```bash
./robot_rf train data/train.csv models/robot_model.bin
```

Windows PowerShell:

```powershell
.\robot_rf.exe train data/train.csv models/robot_model.bin
```

Команда считывает обучающие данные, обучает случайный лес и сохраняет модель в `models/robot_model.bin`.

### Предсказание действий

```bash
./robot_rf predict models/robot_model.bin data/test.csv output.csv
```

Windows PowerShell:

```powershell
.\robot_rf.exe predict models/robot_model.bin data/test.csv output.csv
```

Результаты предсказания сохраняются в `output.csv`. Файл содержит предсказанное действие и вероятность каждого класса.

### Оценка модели

```bash
./robot_rf evaluate models/robot_model.bin data/test.csv
```

Команда выводит:

- Overall accuracy
- Confusion Matrix
- Precision
- Recall
- F1
- Support

### Просмотр важности признаков

```bash
./robot_rf features models/robot_model.bin
```

Команда подсчитывает, сколько раз каждый признак использовался для разделения узлов во всех деревьях, и выводит простую долю важности.

## Параметры конфигурации

Основные параметры находятся в `config.h`:

```c
#define MAX_DEPTH 10
#define N_TREES 50
#define MIN_SAMPLES_SPLIT 2
#define MIN_SAMPLES_LEAF 1
#define N_FEATURES 4
#define N_CLASSES 4
```

Описание параметров:

- `MAX_DEPTH`: максимальная глубина одного дерева решений
- `N_TREES`: количество деревьев в случайном лесе
- `MIN_SAMPLES_SPLIT`: минимальное число образцов для дальнейшего разделения узла
- `MIN_SAMPLES_LEAF`: минимальное число образцов в листовом узле
- `N_FEATURES`: количество входных признаков
- `N_CLASSES`: количество классов действий

## Идея реализации

Случайный лес в этом проекте работает по следующим шагам:

1. Выполняется Bootstrap-выборка из обучающего набора
2. Для каждого дерева случайно выбирается часть признаков при разделении узлов
3. Лучшее разделение выбирается по критерию Gini impurity
4. Несколько деревьев независимо предсказывают класс
5. Финальный класс выбирается большинством голосов

Во время обучения также используются OOB-образцы для оценки качества модели.

## Примечания

- Последний столбец в `data/train.csv` и `data/test.csv` должен быть меткой действия
- Если нужно предсказывать данные без меток, текущий код все равно ожидает последний столбец, поэтому лучше сохранять тот же формат CSV
- Обученная модель по умолчанию сохраняется в `models/robot_model.bin`
- В Windows результат сборки обычно имеет расширение `.exe`
